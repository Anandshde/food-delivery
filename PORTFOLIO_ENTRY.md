## 🎯 Project Overview

A comprehensive food delivery platform that allows users to browse menus, place orders, and track deliveries. Features both customer-facing and administrative interfaces with robust backend services.

### Key Features

- **User Authentication System**: Complete registration, login, and email verification
- **Dynamic Food Menu**: Browse by categories with detailed food information
- **Smart Shopping Cart**: Add/remove items with quantity management
- **Order Management**: Real-time order tracking and status updates
- **Admin Dashboard**: Complete CRUD operations for menu and order management
- **Responsive Design**: Fully optimized for desktop and mobile devices
- **Cloud Integration**: Image storage and email notifications

## 🛠 Tech Stack

### Frontend
- **Next.js 15** with App Router and TypeScript
- **Tailwind CSS** for modern, utility-first styling
- **Radix UI** for accessible component primitives
- **Axios** for API communication
- **Formik & Yup** for form handling and validation

### Backend
- **Node.js & Express** with TypeScript
- **MongoDB Atlas** with Mongoose ODM
- **JWT Authentication** for secure access
- **Cloudinary** for image storage and optimization
- **Nodemailer** for email notifications
- **bcrypt** for password security

### DevOps & Deployment
- **Vercel** for frontend hosting
- **Render.com** for backend deployment
- **MongoDB Atlas** for database hosting
- **GitHub Actions** for CI/CD
